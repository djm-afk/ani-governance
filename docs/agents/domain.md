# 领域文档

本仓采用 single-context，配置工程技能读取术语与决策的方式。

## 领域探索前读取

- 根目录 `GLOSSARY.md`。
- `docs/adr/` 中与当前任务相关的 ADR。

文件尚不存在时静默继续任务，不预先补空文件；术语或决策实际确定后，由 domain-modeling 按需创建。初始化只登记布局，不创建空术语表或 ADR。

## 使用约定

- 票据、分析和实现中使用 `GLOSSARY.md` 已定义的领域术语。
- 需要的概念尚未定义时，先确认它是否属于本仓领域，再记录需要澄清的术语。
- 提议与现有 ADR 冲突时，明确指出对应 ADR 和重新讨论的理由。
- 沿用现有开发指南和领域合同的权威入口；术语表保存术语定义，ADR 保存已接受的决策与取舍。
